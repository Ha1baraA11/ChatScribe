## Возможности

- Копирование всей переписки, последнего ответа ассистента или выбранных сообщений в буфер обмена.
- Выбор отдельных сообщений: фильтрация по автору (пользователь или ассистент), выбор всех или ни одного, инверсия выбора и раскрытие предварительного просмотра.
- Экспорт всей переписки или выбранных сообщений в Markdown, текст, JSON или CSV.
- При необходимости можно скачать изображения из переписки, включая доступные на странице сгенерированные изображения, и упаковать их вместе с Markdown в ZIP. В Markdown используются относительные ссылки на файлы изображений.
- При экспорте в Markdown поддерживаемые шаблоны SVG-диаграмм преобразуются в изображения PNG. В текстовом формате они обозначаются как `[Diagram]`; неподдерживаемые шаблоны сохраняются без изменений.
- Сохранение экспорта Markdown в каталоге `exports/` выбранного репозитория GitHub. Если экспорт содержит изображения, он сохраняется в ZIP.
- Настройка темы, языка интерфейса, заголовков и интервалов между сообщениями, времени экспорта, подтверждения скачивания и включения изображений.

Интерфейс доступен на английском, китайском, немецком, испанском, французском и русском языках. Язык браузера определяется автоматически; если он не поддерживается, используется английский.

## Установка из исходного кода

Используйте Node.js 22 и npm.

### Chrome

~~~sh
npm ci
npm run build:chrome
~~~

Откройте `chrome://extensions`, включите режим разработчика, выберите **Load unpacked** и укажите созданный каталог `dist/`. См. [инструкцию Chrome по загрузке распакованного расширения](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world).

### Firefox

Для настольного Firefox требуется версия 140 или новее, для Firefox на Android — версия 142 или новее.

~~~sh
npm ci
npm run build:firefox
~~~

Откройте `about:debugging`, выберите **This Firefox** и **Load Temporary Add-on**, затем укажите `dist-firefox/manifest.json`. При перезапуске Firefox временные дополнения удаляются. См. [инструкцию Mozilla по временной установке](https://extensionworkshop.com/documentation/develop/temporary-installation-in-firefox/).

Сборка Chrome создаётся в `dist/`, а Firefox — в `dist-firefox/`; каталоги не перезаписывают друг друга.

## Проверки для разработки

~~~sh
npm run typecheck
npm run test:run
npm run build
~~~

CI выполняет эти проверки на Node.js 22. Чтобы собрать расширение для конкретного браузера, используйте `npm run build:chrome` или `npm run build:firefox`.

## Конфиденциальность

Расширение обрабатывает содержимое переписки только для выполнения выбранного вами действия. Данные отправляются в GitHub, только если вы явно выбрали сохранение экспорта туда. См. [политику конфиденциальности](docs/privacy-policy.md): сейчас это черновик на английском языке, перед публикацией необходимо добавить контактные данные сопровождающего.
